What Is Microsoft Copilot?

Microsoft Copilot is Microsoft's AI assistant, built on OpenAI's GPT-4 and integrated across Windows, the web, and Microsoft 365. It launched in 2023 as the successor to Bing Chat and has since become the AI layer running across Microsoft's entire product suite.

There are effectively two versions worth knowing about. The free web version at copilot.microsoft.com — and the Windows 11 sidebar — gives you GPT-4 access with Bing search for no cost. Microsoft 365 Copilot is the enterprise version that works inside Word, Excel, PowerPoint, Outlook, and Teams, and requires a Microsoft 365 subscription plus an add-on fee.

Key Features

Free GPT-4 with Bing Search

The free version of Copilot is powered by GPT-4 and has real-time Bing search built in by default. Every response can draw on current web information without you needing to toggle anything. For users who want up-to-date AI answers without paying $20/month for ChatGPT Plus, this is a genuinely strong alternative. The quality of responses is solid — not identical to ChatGPT's interface, but using the same underlying model.

Windows 11 Integration

Copilot is built into Windows 11 and accessible via a sidebar that can stay open while you work. You can ask it to help draft a document, summarize content you're reading, explain a concept, or perform system tasks like adjusting settings. The always-available sidebar reduces the friction of switching to a browser tab when you want to ask something quickly.

Microsoft 365 Integration

For Microsoft 365 Business subscribers, Copilot works natively inside Word, Excel, PowerPoint, Outlook, and Teams. In Word, it drafts, rewrites, and summarizes. In Excel, it analyzes data, writes formulas, and creates charts from natural language instructions. In Outlook, it summarizes email threads and drafts replies with context. In Teams, it summarizes meetings in real time.

This is the version that competes directly with Google's Gemini for Workspace — and for organizations already running Microsoft 365, it's a compelling add-on. The catch: it's an extra $30/user/month on top of your existing Microsoft 365 plan, which adds up for larger teams.

Image Generation

Copilot includes DALL-E 3 image generation for free — the same model that ChatGPT Plus uses for images. Type a description, get a generated image. Quality is solid and the free access is genuinely generous compared to most platforms that put image generation behind a paywall.

Copilot+ PCs

Microsoft has introduced Copilot+ PCs — hardware with dedicated neural processing units that run certain AI features locally, including real-time caption translation, image generation without internet, and the controversial Recall feature (which screenshots your activity periodically for search). The local processing angle is notable for users who care about privacy, though Recall in particular has attracted significant criticism.

Microsoft Copilot vs ChatGPT: Which Should You Use?

If you don't want to pay anything, Copilot is the best free AI assistant available. Free GPT-4 with Bing search and DALL-E 3 images beats every other free tier on the market right now. For casual use — answering questions, drafting emails, doing research — it handles the job well.

ChatGPT Plus at $20/month earns its price through the features Copilot doesn't match: Advanced Voice Mode, the code interpreter for running Python, better plugin and tool support, and a more conversational interface that feels less corporate. If you use AI heavily every day, ChatGPT Plus is probably worth paying for. If you use it occasionally, Copilot's free tier is more than enough.

For Microsoft 365 power users, the decision is simpler: Copilot inside your existing Office apps is the most practical AI upgrade available for that workflow. No context switching, no copy-pasting — the AI lives where your work already is.

Who Should Use Microsoft Copilot?

Anyone who wants capable AI without paying monthly. The free tier is genuinely good and has no meaningful catches. Windows 11 users get it built into their OS. Microsoft 365 Business users should seriously evaluate the enterprise add-on — the meeting summaries and document drafting alone can justify the cost for teams that spend significant time in those workflows.
